# CareerCompass

CareerCompass is a career recommendation web app that helps users discover suitable careers, refine their choices using natural-language input, and identify skill gaps for a chosen career path. It combines a RIASEC personality-based recommender, an NLP-driven hybrid recommender, and a skill gap analysis tool into a single Flask-powered application.

## Features

- **Objective 1 — RIASEC Career Matcher**
  Presents a 30-question RIASEC (Realistic, Investigative, Artistic, Social, Enterprising, Conventional) questionnaire, builds a user interest profile, and recommends the top 5 matching careers using cosine similarity and distance-based scoring against O*NET occupation data.

- **Objective 2 — NLP Hybrid Recommender**
  Takes a free-text description of the user's interests, processes it with NLTK (tokenization, stopword removal, lemmatization), and uses TF-IDF + cosine similarity to find the top 10 careers that best match both the text and the Objective 1 RIASEC profile.

- **Objective 3 — Skill Gap Analysis**
  Given a selected career and the user's current skills, matches the career to a skills database (using exact, substring, and TF-IDF/sequence-matching hybrid search) and reports which required skills the user already has versus which they still need, along with a coverage percentage.

## Tech Stack

- **Backend:** Python, Flask, Flask-CORS
- **Data processing:** pandas, NumPy, scikit-learn, NLTK
- **Frontend:** HTML, CSS, vanilla JavaScript (served as static files by Flask)

## Getting Started

### Prerequisites

- Python 3.9+
- pip

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/BazazAnas/Final-Project.git
   cd Final-Project
   ```

2. Install the backend dependencies:
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

3. Ensure the dataset paths in `backend/app.py` point to your local dataset locations (by default they point to `../DataSets/`).

### Running the App

From the `backend` directory:

```bash
python app.py
```

Then open your browser at [http://localhost:5000](http://localhost:5000).

## API Endpoints

| Method | Endpoint            | Description                                                  |
|--------|----------------------|----------------------------------------------------------------|
| GET    | `/api/questions`     | Returns the RIASEC questionnaire                               |
| POST   | `/api/objective1`     | Takes RIASEC answers, returns top 5 matching careers + profile |
| POST   | `/api/objective2`     | Takes free-text interests, returns top 10 hybrid recommendations |
| POST   | `/api/objective3`     | Takes a selected career + user skills, returns skill gap analysis |

### Example: `/api/objective1`
```json
{
  "answers": {
    "Realistic": [1, 3, 5, 2, 4],
    "Investigative": [4, 4, 3, 5, 5],
    "Artistic": [2, 3, 1, 2, 3],
    "Social": [3, 4, 5, 4, 3],
    "Enterprising": [2, 3, 2, 1, 2],
    "Conventional": [3, 2, 4, 3, 3]
  }
}
```

### Example: `/api/objective2`
```json
{
  "user_text": "I love working with data, solving problems, and building things with code."
}
```

### Example: `/api/objective3`
```json
{
  "selected_title": "Data Scientist",
  "user_skills": "python, sql, excel, communication"
}
```

## How It Works

1. The user completes the RIASEC questionnaire (Objective 1), producing a ranked list of careers based on personality-interest fit.
2. The user optionally describes their interests in free text (Objective 2), which is blended with the Objective 1 results to refine the recommendations using NLP-based text similarity.
3. The user selects a career and lists their current skills (Objective 3), and the app identifies which required skills they already have and which ones represent a gap to close.
